# 🏮 بلاگ فانوس (Fanoos Blog)

فانوس بلاگ کاری از تیم دیزاین **همکاران سیستم** برای اشتراک دانش، تجربیات و آموزش‌های حوزه هوش مصنوعی (AI) و فرآیندهای طراحی مدرن است.

این پروژه یک وبلاگ استاتیک و مینیمال است که به صورت کاملاً کلاینت‌ساید (بدون نیاز به مرحله بیلد) فایل‌های مارک‌داون را رندر می‌کند.

---

## ⚡ ویژگی‌ها
- **رندر سریع مارک‌داون:** تبدیل خودکار فایل‌های `.md` به صفحات وب با استفاده از جاوااسکریپت و کتابخانه `markdown-it`.
- **بدون نیاز به فریم‌ورک:** طراحی خالص با HTML، CSS و Vanilla JS برای بالاترین سرعت لود.
- **تم تاریک و روشن:** هماهنگی خودکار با تم سیستم‌عامل کاربر به همراه دکمه تغییر تم دستی.
- **سیستم تگ‌گذاری:** امکان دسته‌بندی و فیلتر مقالات بر اساس موضوعات مختلف.
- **دیپلوی خودکار:** اتصال مستقیم به گیت‌هاب و دیپلوی آنی با هر Push روی سرور Vercel.

---

## 🛠️ ساختار پروژه
```text
fanoos-blog/
├── index.html           ← صفحه اصلی (لیست مقالات)
├── post.html            ← صفحه نمایش هر مقاله
├── CSS/style.css        ← سیستم دیزاین بلاگ
├── js/app.js            ← هسته اجرایی (تغییر تم، واکشی و رندر مارک‌داون)
├── posts/
│   ├── index.json       ← رجیستری و متادیتای مقالات (ترتیب نمایش)
│   └── *.md             ← فایل‌های مارک‌داون مقالات خام
└── [TODO.md](TODO.md)              ← نقشه راه و ایده‌های توسعه آینده
```

## 🔮 کارهای آینده (Roadmap)
ایده‌ها، ویژگی‌ها و برنامه‌های آینده برای توسعه بلاگ فانوس در فایل [TODO.md](TODO.md) لیست شده‌اند.

---

## 💻 اجرای محلی (Local Run)
برای اجرای صحیح بلاگ به صورت محلی، نیاز به یک سرور استاتیک ساده دارید تا فایل‌های JSON و Markdown بدون مشکل CORS لود شوند:

```bash
# با استفاده از Vercel Dev (پیشنهادی)
npx vercel dev

# یا استفاده از پایتون
python3 -m http.server 8000
```

---

## ✍️ چطور پست جدید بنویسیم؟ (بدون درگیری با کد!)
برای نوشتن پست جدید نیازی نیست وارد جزئیات کدهای پروژه یا فایل رجیستری (`posts/index.json`) بشید. ما این فرآیند رو با یک **Agent Skill** هوشمند اتوماتیک کردیم تا در زمان صرفه‌جویی بشه:

1. کافیه ایده یا پیش‌نویس (Draft) اولیه خودتون رو به ایجنت AI بدید.
2. اسکیل هوشمند بلاگ‌نویس (`fanoos-blog-writer`) فعال می‌شه و:
   - در مورد موضوع دقیق ریسرچ می‌کنه.
   - پست رو با لحن صمیمی و روان مناسب برای دیزاینرها آماده می‌کنه.
   - فایل مارک‌داون مقاله را در پوشه `posts/` می‌سازه.
   - متادیتای مقاله رو به طور خودکار به فایل `posts/index.json` اضافه می‌کنه.
3. در نهایت بعد از تایید شما، تغییرات کامیت می‌شن تا بلافاصله روی Vercel منتشر بشن!

---

## 🤝 نحوه مشارکت روی پروژه
اگر می‌خواهید در توسعه قابلیت‌های بلاگ مشارکت کنید یا ایده جدیدی پیاده کنید:
1. پروژه را کلون کنید و با استفاده از دستورات بخش **Local Run** آن را به صورت محلی اجرا کنید.
2. تغییرات خود را روی یک برنچ جدید اعمال کنید.
3. ایده‌ها و ویژگی‌های جدیدی که برای توسعه بلاگ در نظر دارید را می‌توانید در فایل [TODO.md](TODO.md) ثبت کنید.
4. پس از اطمینان از صحت عملکرد، تغییرات را کامیت و پول‌ریکوئست (PR) کنید.
